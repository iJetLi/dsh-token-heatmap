# DSH 0.1.5-rc.3 / 0.1.7-rc.2 兼容层实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `dsh-token-heatmap` 同时兼容 DSH 0.1.5-rc.3 与 0.1.7-rc.2，在两版上热力图与完整配置卡均可用。

**Architecture:** `export const inject` 只声明两版交集服务；版本差异全部下沉到 `apply()` 体内的两路 `ctx.inject(deps, cb)` 条件分支——服务缺席的那路永久 pending（cordis 原生降级语义），不靠 `try/catch` 吞服务解析异常。同时清理两版都失效的 persisted 折叠死代码。

**Tech Stack:** Node.js ESM（无构建步骤）、cordis 插件协议、schemastery、手写 `window.__ModuleLoader__` 浏览器 bundle、React 18（测试时从 DSH profile 的 node_modules 解析）。

**Spec:** `docs/superpowers/specs/2026-09-25-dsh-015-017-compat-design.md`

## Global Constraints

- 目标版本：**DSH 0.1.5-rc.3** 与 **DSH 0.1.7-rc.2**（DSH 源码：`D:\jet\code\js\deepseek-harness`，tag `dsh-v0.1.5-rc.3` / `dsh-v0.1.7-rc.2`）
- **禁止调用 `.volatile()`** —— 0.1.5 的 schemastery 3.18.2 没有它。必须用 `schema.extra("volatile", true)`（两版都有 `extra`，0.1.7 的 `.volatile()` 实现即 `this.extra('volatile', true)`）
- `export const inject` **只能**包含两版都存在的服务。服务端保持 `["webServer","sessions","sessionPersistence","settings"]` 不变；客户端必须是 `["slots","locale","connection","remote"]`（**不含** `settingsScope`）
- 禁止用 `try/catch` 捕获服务解析异常来分支 —— cordis 显式抛 `cannot get property "..." without inject`
- 客户端 bundle key `@kidli1412/dsh-token-heatmap` 硬编码（浏览器端无法 import 自身 `package.json`），必须与 `package.json` 的 `name` 一致
- 配置 namespace 恒为 `"token-heatmap"`（同时是 profile patch 里的 entry id）
- `CACHE_VERSION` 保持 **2**（死代码清理已证明行为等价，不触发重折）
- `version` → **`0.1.8`**；`dshReleases` **只**声明 `0.1.5-rc.3` 与 `0.1.7-rc.2`
- `engines.dsh` 与 9 项 `peerDependencies` **不改**（`^0.1.2-rc.1` = `>=0.1.2-rc.1 <0.2.0`，已覆盖目标版本）
- **不新增** `dsh-client-ui-plugin-manager` peer（0.1.5 无此包，会导致解析失败）
- 每个任务结束前必须 `npm run check && npm test` 全绿

function makeMinimalScope() {
	let snapshot = { status: "loading", value: void 0, writable: false, mode: "host" };
	const listeners = new Set();
	return {
		getSnapshot: () => snapshot,
		subscribe: (l) => { listeners.add(l); return () => listeners.delete(l); },
		set: async () => {},
		unset: async () => {}
	};
}

/**
 * A client context for one train. The root context and the child handed to
 * ctx.inject's callback share one slot recorder — in cordis the child inherits
 * the parent's slot service, so registrations made inside a branch must be
 * visible on the root.
 */
function makeClientCtx(providedServices) {
	const registered = [];
	const injectedSlots = [];
	const slots = {
		register: (options, component) => { registered.push({ options, component }); return () => {}; },
		inject: (name) => { injectedSlots.push(name); return () => {}; }
	};
	const ctx = {
		registered,
		injectedSlots,
		slots,
		locale: { register: () => () => {} },
		effect: (fn) => fn(),
		// cordis semantics: the callback runs ONLY when every requested service
		// is present; otherwise that fiber stays pending, silently. The child
		// handed to the callback shares the root's slot service — in cordis a
		// child context inherits its parent's services — so registrations made
		// inside a branch are recorded on the root too.
		inject: (deps, callback) => {
			if (deps.every((d) => providedServices.has(d))) callback(ctx.child);
		}
	};
	ctx.child = { slots, effect: (fn) => fn() };
	return ctx;
}
